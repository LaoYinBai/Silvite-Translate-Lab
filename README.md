# 🌐 Silvite Translate Lab

> 一个会“读上下文”的 AI 翻译台。不只是把字换成另一种语言，还会想想这句话到底在说什么。

**在线体验**：👉 **[translate.modiconnect.cn](https://translate.modiconnect.cn)**

打开就能用，不需要安装任何东西。

---

## 它是做什么的

我平时翻译、读外文资料时，最烦的就是机翻“字对字”：同样一个“窗口”，在电脑界面里是 `window`，在项目排期里是 `time window`，机器却常常分不清。

这个小工具就是为了解决这种“看着对、读着别扭”的问题：

- **不用选语言**：中文自动译成英文，英文和其他语言自动译成中文。
- **六种风格**：自然、文学、学术、商务、漫画，外加一个让 AI 自己判断的 Auto。
- **会参考上下文**：你可以补充背景，它只拿来理解句子的意思，不会把背景硬翻进正文。
- **术语你说了算**：比如指定“墨堤 → MoDi Connect”，它会按你的译法来。
- **能看图**：海报、截图、漫画都可以直接拖进来翻译。
- **文件也行**：PDF、Word、Markdown、字幕文件等，都在浏览器里本地读取。

---

## 三步上手

1. 打开网站，把文字粘进去；或者直接拖一张图、一个文件进来。
2. 如果需要，展开 **Context** 写几句背景，比如“这是一款游戏的界面文字”。
3. 点翻译，等几秒。满意就复制，或者导出为 PDF / Word / Markdown。

---

## 几个小贴士

- 有固定译法的词，放进 **Terminology**，它会优先遵守。
- 想知道 AI 为什么这样译，打开 **翻译说明**，里面会解释专有名词、文化表达和语气上的取舍。
- 你的翻译会自动保存在**当前浏览器**的“翻译历史”里，可以随时搜索、恢复，也能导出备份。API 密钥和原始附件不会被保存。

## 它还在实验中

这是一个实验性项目，AI 翻译仍会出错，尤其是：

- OCR 识别不准的图片
- 版面很复杂的文件
- 漫画里气泡归属和阅读顺序
- 冷门语言和专业领域的术语
- 有正式官方译名要求的内容

重要内容，请人工复核最后的译文。

## 语料工具（实验）

网站里还有一个 **中英语料工具**，可以导入导出 TMX，对齐中英文档，并把 TMX 实验性导出为 SDLTM 格式。所有处理都在浏览器里完成。

SDLTM 导出仍在验收中，不保证 Trados 完全兼容。

## 想自己跑起来的人

本地运行需要 Node.js，并且需要你自己准备一个兼容的模型接口密钥。

```bash
git clone https://github.com/LaoYinBai/Silvite-Translate-Lab.git
cd Silvite-Translate-Lab
npm ci
```

在项目根目录新建 `.env.local`，参考 `.env.example` 填入你自己的配置。**密钥不要提交到仓库。**

然后分两个终端分别运行：

```bash
npm run api   # 启动本地翻译接口
npm run dev   # 启动前端页面
```

架构、部署和设计思路见 [DEV.md](DEV.md) 与 [DESIGN.md](DESIGN.md)。
