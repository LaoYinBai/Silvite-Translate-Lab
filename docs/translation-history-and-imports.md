# 翻译历史与首页文档导入

2026-11-07。网站主页仍为翻译，历史和语料工具从侧栏或手机菜单进入。

## 翻译历史

完成一次真实翻译后，原文快照、完整译文、分段对照、翻译说明和本次请求设置自动写入当前浏览器的 IndexedDB。后台 AI 对照完成后更新同一条记录，不另生成重复历史。演示、失败结果和流式草稿不进入历史；不保存 API 密钥或上传附件本体。原始文档和图片恢复为已提取或识别的文字。

“翻译历史”可搜索、恢复到翻译页、删除，以及导出全部已保存记录为 JSON。备份采用 `silvite-translation-history` 格式、版本 1。导入先完整校验，再在单个事务中合并；重复 ID 保留现有记录。无效字段、范围、版本或容量超限时整份不导入，不覆盖现有内容。

恢复历史不重新请求翻译。新建翻译、重译和历史恢复会隔离旧的后台任务；恢复尚在生成分段的记录时，有预分段则设为可用，否则提供重新分段，避免永久“准备中”。删除期间收到的分段更新暂存；删除成功丢弃，删除失败尽力保存最新快照，失败时保留重试入口。

历史最多 1,000 条、单条 6 MiB、总量 28 MiB，JSON 备份最多 30 MiB。达到上限不自动删除旧记录。存储失败会显示错误，可重试；JSON 导出仅包含成功保存的记录。浏览器清理网站数据会删除本地历史，跨设备需自行导出／导入备份。

## 首页导入范围

| 类型 | 支持范围与行为 |
| --- | --- |
| TXT | UTF-8、UTF-8 BOM、带 BOM 的 UTF-16 LE/BE；无效或未知编码明确提示另存 UTF-8，不以替换字符吞掉错误 |
| PDF | 提取可读文字层，保留独立数字行和重复正文；无可提取正文的扫描页、混合文本／扫描页提示改用“视觉翻译（逐页识别）” |
| DOCX | 保留正文、标题、列表／表格文本；HTML 实体只解码一次，源文中真实的 `&lt;` 等字面字符串不会被再次替换 |
| 旧 DOC | 由浏览器 Office WASM 读取真实 OLE 文件；加载中断后允许重试，释放已解析文档占用的 WASM 资源 |

TXT / PDF / DOCX 等输入最大 10 MiB，DOC / PPT / PPTX / XLSX 最大 25 MiB；提取正文上限 100,000 字符。PDF 字体、CMap、解码器和 Worker 作为本站静态资源发布。PDF 同一页中图像是否包含额外正文无法仅凭文字层可靠判断；扫描识别仍需用户选择视觉路径，不承诺任意 PDF 结构都能无损还原。

选文件、拖拽和粘贴共用同一入口。较早的慢任务不能覆盖后选文件，清空、切换页面或新建翻译后旧结果不会重新挂回；成功导入清除旧的附件错误，读取期间不发送尚未完成的文档。
